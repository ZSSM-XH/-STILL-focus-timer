# STILL · 专注与片刻

一个简单的专注计时与休息仪式网站。

## 功能

- 专注计时
- 随机片刻
- 灵感点数
- 抛硬币与骰子
- 历史记录
- 多套装扮
- 日间 / 夜间模式
- 白噪音
- 移动端适配

## 数据

无需登录。

数据保存在浏览器本地。

## 部署

项目通过 GitHub Pages 部署。
https://zssm-xh.github.io/-STILL-focus-timer/

## 状态

这是一个未完成的小项目，主要作为个人实验与记录。

目前推荐使用电脑端访问，移动端适配并不完善。

之后大概率不会继续维护。
