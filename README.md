# STILL · 专注与片刻

一个简单的专注计时与休息仪式网站。

## 功能

- 专注计时
- 随机片刻
- 灵感点数
- 抛硬币与骰子
- 历史记录
- 多套装扮
- 日间 / 夜间模式
- 白噪音
- 移动端适配

## 数据

无需登录。

数据保存在浏览器本地。

## 部署

项目通过 GitHub Pages 部署。
https://zssm-xh.github.io/-STILL-focus-timer/

## 状态

这个项目目前还没有完全完成，之后大概率也不会继续更新。

更推荐在电脑端使用。
手机端虽然可以打开，但部分页面的排版和体验还不够完善。
